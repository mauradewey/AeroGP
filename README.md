## AeroGP

AeroGP is a climate emulator which predictes the global spatially resolved surface temperature response to regional anthropogenic aerosol perturbations. 

The processed training data and model code are also archived here: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17099941.svg)](https://doi.org/10.5281/zenodo.17099941)

The associate paper is currently under review at JGR: Machine Learning and Computation
